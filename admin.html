Repositorio (normalmente no hace falta tocarlo)

¿Cómo consigo un token?
  1. Pide a quien administre el repositorio que te añada como colaborador (Settings → Collaborators).
  2. En GitHub abre Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Repository access elige Only select repositories y marca solo el repositorio de la web.
  4. En Permissions → Repository permissions pon Contents: Read and write.
  5. Genera el token, cópialo y pégalo arriba. GitHub solo lo muestra una vez. Ponle una caducidad corta (por ejemplo, 90 días).
